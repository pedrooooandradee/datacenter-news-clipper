Clipping 247 - Comandos (terminal do Cursor: menu Terminal > New Terminal)
Explicação de cada um em LEIA-ME.md

─────────────────────────────────────────────────────────────────────────────
O DIA A DIA
─────────────────────────────────────────────────────────────────────────────

1) Ativar o ambiente (só se o terminal não mostrar "(venv)" no início da linha):
source venv/bin/activate

2) Rodar o clipping completo (busca + IA + PDF).
   SÓ COM AUTORIZAÇÃO. Gasta dinheiro de API e leva de 10 a 30 minutos:
python main.py

3) Refazer só o PDF, de graça, em segundos.
   Use depois de mexer em configs/overrides.json:
python services/pdf_builder.py

─────────────────────────────────────────────────────────────────────────────
REFAZER SÓ UMA ETAPA, SEM REPAGAR AS ANTERIORES
─────────────────────────────────────────────────────────────────────────────

Etapas, em ordem:
   search  classify  scrape  summarize  ficha  dedup  pdf

python main.py --from=summarize     refaz do resumo em diante
python main.py --from=ficha         refaz ficha, métricas e categoria final
python main.py --from=dedup         refaz só a deduplicação
python main.py --list-cache         mostra o que está guardado
python main.py --clear-cache        apaga o cache e SAI (não roda nada)

ATENÇÃO: --from reescreve o output/clippings.json. A versão anterior fica em
output/clippings.anterior.json, mas correção feita à mão só sobrevive de verdade
se estiver em configs/overrides.json.

─────────────────────────────────────────────────────────────────────────────
CONFERIR QUE O PROGRAMA CONTINUA CERTO (de graça, 1 segundo, sem internet)
─────────────────────────────────────────────────────────────────────────────

Depois de mexer em qualquer arquivo de configuração ou de código:
python -m unittest discover -s tests

São 66 testes das regras que decidem o que o investidor lê: qual número pode ser
publicado, qual veículo vence uma duplicata, qual empresa ganha caixa e o que
cada correção manual faz. Se algum falhar, NÃO envie o clipping.

─────────────────────────────────────────────────────────────────────────────
CORRIGIR A EDIÇÃO
─────────────────────────────────────────────────────────────────────────────

NÃO edite mais o output/clippings.json à mão - ele é reescrito na execução
seguinte. Escreva em configs/overrides.json (blocos: removidas, categoria,
resumo, highlight, fonte_nome, dedup, empresa) e rode o comando 3.

A chave é sempre a URL da matéria. O campo "motivo" é obrigatório em removidas,
categoria, resumo e dedup.

─────────────────────────────────────────────────────────────────────────────
ANTES DE ENVIAR
─────────────────────────────────────────────────────────────────────────────

Leia o que o programa imprime no fim. Se aparecer

   🚨 RESUMOS CITAM NÚMERO QUE NÃO ESTÁ NA MATÉRIA

abra o link e confira o número antes de enviar.

─────────────────────────────────────────────────────────────────────────────
MONTAR O PROJETO DO ZERO (uma vez só)
─────────────────────────────────────────────────────────────────────────────

PRECISA ANTES: Google Chrome instalado (a coleta abre as páginas nele) e as
bibliotecas libpango e libcairo, que o pip NÃO instala. Dois caminhos; escolha
um e não misture. O passo a passo está no LEIA-ME.md.

A) Homebrew (o normal em Mac):
brew install cairo pango gdk-pixbuf libffi
python3 -m venv venv

B) conda (é o que está montado na máquina em que o programa foi escrito):
conda create -p ~/.clipping247-python -c conda-forge python=3.12 pango cairo
~/.clipping247-python/bin/python3 -m venv venv

Depois, dos dois jeitos:
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        e preencha a chave da OpenAI
