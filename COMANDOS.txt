Clipping 247 - Comandos (terminal do Cursor: menu Terminal > New Terminal)
Explicação de cada um em LEIA-ME.md

Cada comando está sozinho na linha, para copiar e colar a linha inteira. O que
ele faz está sempre na linha de cima.

─────────────────────────────────────────────────────────────────────────────
O DIA A DIA
─────────────────────────────────────────────────────────────────────────────

1) Ativar o ambiente (só se o terminal não mostrar "(venv)" no início da linha):
source venv/bin/activate

2) Rodar o clipping completo (busca + IA + PDF).
   SÓ COM AUTORIZAÇÃO DO DONO DO CLIPPING. Gasta dinheiro de API e leva de 10
   a 30 minutos. Tudo o que aparece no terminal fica salvo em output/logs/:
python main.py

3) Refazer só o PDF, de graça, em segundos.
   Use depois de mexer em configs/overrides.json:
python services/pdf_builder.py

─────────────────────────────────────────────────────────────────────────────
REFAZER SÓ UMA ETAPA, SEM REPAGAR AS ANTERIORES
─────────────────────────────────────────────────────────────────────────────

Etapas, em ordem:
   search  classify  scrape  summarize  ficha  dedup  pdf

Refaz do resumo em diante:
python main.py --from=summarize

Refaz ficha, métricas e categoria final, e o que vem depois:
python main.py --from=ficha

Refaz a deduplicação e o PDF:
python main.py --from=dedup

Mostra o que está guardado:
python main.py --list-cache

Apaga o cache e SAI (não roda nada):
python main.py --clear-cache

ATENÇÃO: --from reescreve o output/clippings.json e FECHA A EDIÇÃO DE NOVO COM A
DATA DE HOJE (cabeçalho do PDF e pasta do arquivo). A versão anterior fica em
output/clippings.anterior.json, mas correção feita à mão só sobrevive de verdade
se estiver em configs/overrides.json. Para corrigir uma edição já montada, use o
comando 3 (refazer só o PDF), não o --from.

─────────────────────────────────────────────────────────────────────────────
CONFERIR QUE O PROGRAMA CONTINUA CERTO (de graça, 1 segundo, sem internet)
─────────────────────────────────────────────────────────────────────────────

Depois de mexer em qualquer arquivo de configuração ou de código:
python -m unittest discover -s tests

São os testes das regras que decidem o que o investidor lê: qual número pode ser
publicado, qual veículo vence uma duplicata, qual empresa ganha caixa e o que
cada correção manual faz. Se algum falhar, NÃO envie o clipping.

─────────────────────────────────────────────────────────────────────────────
CORRIGIR A EDIÇÃO
─────────────────────────────────────────────────────────────────────────────

NÃO edite mais o output/clippings.json à mão - ele é reescrito na execução
seguinte. Escreva em configs/overrides.json (blocos: removidas, categoria,
resumo, highlight, fonte_nome, dedup, empresa) e rode o comando 3.

A chave é sempre a URL da matéria. O campo "motivo" é obrigatório em removidas,
categoria, resumo e dedup. Ponha "data" (AAAA-MM-DD, o dia da edição) em toda
correção, menos no highlight. Se faltar ou sobrar uma vírgula, o PDF não sai e o
programa diz a linha.

Edição montada e NÃO enviada: renomeie a pasta dela em output/archive/ para
AAAA-MM-DD-nao-enviada. Senão, a semana seguinte retira as notícias dela como
"já enviadas".

─────────────────────────────────────────────────────────────────────────────
ANTES DE ENVIAR
─────────────────────────────────────────────────────────────────────────────

Faça a "Revisão da edição, item a item" do LEIA-ME.md, com o PDF da semana,
o PDF da edição anterior (output/archive/) e o registro (output/logs/) abertos.
Na edição de 28/09, 11 de 36 notícias precisaram de correção, e nenhum desses
erros aparecia no terminal.

─────────────────────────────────────────────────────────────────────────────
MONTAR O PROJETO DO ZERO (uma vez só)
─────────────────────────────────────────────────────────────────────────────

SÓ MAC. O passo a passo com explicação está no README.md (uns 20 minutos).
Precisa antes: Git, Google Chrome e conda (Miniforge) instalados.

Cria o Python do projeto (Mac com chip Intel: sem o "CONDA_SUBDIR=osx-arm64"
do começo):
CONDA_SUBDIR=osx-arm64 conda create -y -p ~/.clipping247-python --override-channels -c conda-forge python=3.12 pango cairo gdk-pixbuf libffi

Monta o venv a partir dele e ativa:
~/.clipping247-python/bin/python3 -m venv venv
source venv/bin/activate

Tem de dizer 3.12:
python --version

Mac com chip Apple: tem de dizer arm64:
python -c "import platform; print(platform.machine())"

Instala as bibliotecas nas versões que rodaram:
pip install -r requirements.lock.txt

Cria o .env; depois abra e ponha a chave da OpenAI da empresa:
cp .env.example .env

Tem de terminar em OK:
python -m unittest discover -s tests

NÃO use "python3 -m venv venv" com o Python do Mac: ele é o 3.9 e as
bibliotecas exigem 3.10 ou mais.

Computador novo, ou mais de um computador: antes de rodar, copie para
output/archive/ a pasta da última edição ENVIADA (fica na pasta da empresa).
Cada computador só conhece as edições que saíram dele.
